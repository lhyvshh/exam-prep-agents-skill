# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the default branch.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include private books, exam files, answer keys, API credentials, or learner data in a public issue.

When possible, include a minimal synthetic reproduction, affected version, impact, and suggested mitigation. Reports are acknowledged as soon as practical, and confirmed issues are fixed before public disclosure.

## Trust Boundary

The skill executes local scripts and reads only files the user or host agent selects. Review the skill before installation and follow your agent host's permission prompts. Generated HTML is designed to be network-free and stores progress locally in the browser.
